# 高校化學前哨戰｜hschem

互動式自主學習網站專案。

## 目前範圍

- 現行前端基準：Class 01–05
- 前五課 28 個原練習已有前端互動
- Class 06–10 尚未納入本階段
- 作答目前仍以前端頁面狀態為主，尚未完成正式雲端保存
- 後端預計以 Supabase 逐步建立與驗證

## 專案原則

1. 優先重用既有 Class 01–05 成果，不重新製作五課。
2. 先完成可驗證的最小後端閉環，再逐步擴充。
3. 教材內容、教師答案、前端提示與修訂提案保持來源邊界。
4. 不將私密金鑰、密碼、 service role key、token 或 credentials 提交到 Git。
5. 私人預覽、教材影像與尚未確認可發布的素材，不直接作為公開部署內容。
6. 模型檢查不等同人工核定；未知狀態不視為零。

## 目錄

- `frontend/`：學生端網站程式
- `backend/`：必要的後端整合程式
- `supabase/`：可版本化的 schema / migration / 設定
- `docs/`：專案文件與部署說明
